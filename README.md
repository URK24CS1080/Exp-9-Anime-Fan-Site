# Experiment 9: Working with MongoDB Using Shell Commands

## Aim
To perform basic MongoDB database operations using MongoDB Shell for the AnimeVerse website.

## Description
MongoDB is a NoSQL database that stores data in document format. In this experiment, MongoDB Shell (`mongosh`) is used to create a database and collection, insert anime records, retrieve and search records, update ratings, delete records, and sort anime by rating.

## Technologies Used
- MongoDB Community Server
- MongoDB Shell (`mongosh`)

## Database Details
- **Database:** `AnimeVerseDB`
- **Collection:** `animes`
- **Fields:** `title`, `genre`, `rating`

## Operations Performed
1. Created the AnimeVerseDB database and animes collection.
2. Inserted anime records.
3. Retrieved all anime records.
4. Searched anime by genre.
5. Updated an anime rating.
6. Deleted an anime record.
7. Sorted anime records by rating.

## Result
Thus, basic database operations were performed successfully using MongoDB Shell for the AnimeVerse website.
